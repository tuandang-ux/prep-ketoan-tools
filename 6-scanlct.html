Quét ảnh ĐNTT bằng Google Gemini AI

Cần cấu hình API key Google Gemini trước khi quét.
Bấm nút "⚙ Cài đặt" trên thanh công cụ để nhập API key — bạn sẽ được hướng dẫn lấy key miễn phí từ Google AI Studio.
✨ Cách hoạt động: AI sẽ tự động trích xuất từng ĐNTT và thêm vào danh sách đối chiếu — bạn không cần xác nhận thủ công. Nếu thấy AI đọc sai, bấm vào ảnh để xem/sửa lại.

⏱ Thời gian quét: Vì free tier của Gemini giới hạn 10-15 lần gọi/phút, tool tự giãn cách ~6 giây/ảnh (Flash) hoặc ~4.5 giây/ảnh (Flash-Lite) để tránh bị chặn. Nếu cần quét nhiều ảnh nhanh hơn, đổi sang "Gemini 2.5 Flash-Lite" trong Cài đặt (15 lần/phút). Nếu bị 429, tool tự đợi và retry.

Cài đặt Gemini AI

API Key

Key được lưu cục bộ trong trình duyệt (localStorage), không bao giờ gửi đi đâu khác ngoài Google API.

→ Lấy API key miễn phí tại Google AI Studio

Hướng dẫn nhanh:

  1. Mở link trên, đăng nhập bằng tài khoản Google
  2. Bấm "Create API key" → Copy chuỗi bắt đầu bằng AIzaSy...
  3. Dán vào ô trên và bấm Lưu

Model AI

Free tier hiện có cho các model Flash. Pro models có thể yêu cầu billing tài khoản.

Cấu hình cột của file LCT

Mỗi cột đã được tự động phát hiện theo tên tiêu đề. Nếu file của bạn cấu trúc khác, hãy điều chỉnh lại.

Tool offline — lưu file HTML này về máy và mở bằng trình duyệt. Lần đầu cần internet để tải SheetJS + Tesseract.js, sau đó cache offline.
